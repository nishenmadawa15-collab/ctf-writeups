## Write-up template

Each write-up follows the same structure (`TEMPLATE.md`):

1. **Challenge** — name, platform, category, points
2. **Objective** — what the flag represents
3. **Recon / clues** — what was given, first observations
4. **Methodology** — step by step, with commands and output
5. **Mistakes** — dead ends and why they failed
6. **Lessons learned** — the reusable takeaway
7. **Remediation** — how the vulnerability would be fixed in the real world
